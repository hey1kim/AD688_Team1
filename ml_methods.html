1 Overview

This section applies machine learning models to the 2024 Lightcast job postings dataset to analyze AI vs. Non-AI career patterns using PySpark MLlib. Two approaches are used: KMeans Clustering (unsupervised) to discover natural job groupings, and Logistic Regression + Random Forest (supervised) to predict whether a job is AI-related.

2 Creating the AI Job Indicator

Following the same methodology established in the Data Cleaning section, jobs are classified as AI-related using keyword matching on title and skill fields.

ai_keywords_exact = [
    r"\bai\b", r"\bllm\b", r"\bmlops\b", r"\bnlp\b",
    r"\bml engineer\b", r"\btensorflow\b", r"\bpytorch\b"
]
ai_keywords_partial = [
    "artificial intelligence", "machine learning", "deep learning",
    "data scientist", "generative ai", "reinforcement learning",
    "computer vision", "large language model", "predictive modeling",
    "natural language processing", "neural network", "data science",
    "data engineer", "data analyst", "statistical modeling",
    "predictive analytics", "business intelligence"
]

def is_ai(title):
    t = str(title).lower()
    for kw in ai_keywords_exact:
        if re.search(kw, t): return 1
    for kw in ai_keywords_partial:
        if kw in t: return 1
    return 0

is_ai_udf = udf(is_ai, IntegerType())
sdf = sdf.withColumn("AI_JOB", is_ai_udf(col("TITLE_RAW")))
sdf.cache()

ai_counts = sdf.groupBy("AI_JOB").count().orderBy("AI_JOB").toPandas()
ai_counts.columns = ["AI Job", "Count"]
ai_counts["AI Job"] = ai_counts["AI Job"].map({0: "Non-AI", 1: "AI-Related"})
print(ai_counts)

3 KMeans Clustering

KMeans clustering groups job postings based on occupational characteristics — experience requirements, education level, and SOC classification — to identify whether AI-related jobs form distinct natural clusters.

A data quality issue was identified during feature preparation: the MIN_EDULEVELS field uses the code 99 to mean “No Education Listed” — a missing-data flag rather than a true ordinal education level. Left uncorrected, this placeholder distorts distance-based clustering. We replace it with the median of valid education levels before clustering.

valid_edu = sdf.filter(col("MIN_EDULEVELS") != 99)
median_edu = valid_edu.approxQuantile("MIN_EDULEVELS", [0.5], 0.01)[0]
sdf = sdf.withColumn(
    "MIN_EDULEVELS_CLEAN",
    when(col("MIN_EDULEVELS") == 99, median_edu).otherwise(col("MIN_EDULEVELS"))
)
print(f"Median valid education level used for imputation: {median_edu}")

indexer_soc = StringIndexer(inputCol="SOC_2021_5", outputCol="SOC_ENC", handleInvalid="keep")
indexer_onet = StringIndexer(inputCol="ONET", outputCol="ONET_ENC", handleInvalid="keep")
sdf = indexer_soc.fit(sdf).transform(sdf)
sdf = indexer_onet.fit(sdf).transform(sdf)

cluster_features = ["MIN_YEARS_EXPERIENCE", "MIN_EDULEVELS_CLEAN", "SOC_ENC"]
assembler = VectorAssembler(inputCols=cluster_features, outputCol="features_raw")
sdf_vec = assembler.transform(sdf)

scaler = StandardScaler(inputCol="features_raw", outputCol="features", withMean=True, withStd=True)
scaler_model = scaler.fit(sdf_vec)
sdf_scaled = scaler_model.transform(sdf_vec).cache()

3.1 Elbow Method and Silhouette Score

To determine the optimal number of clusters, we evaluate KMeans across k = 2 to 7 using both inertia (elbow method) and silhouette score.

evaluator = ClusteringEvaluator(featuresCol="features", predictionCol="prediction")
elbow_rows = []
for k in range(2, 8):
    km = KMeans(featuresCol="features", k=k, seed=42)
    model = km.fit(sdf_scaled)
    cost = model.summary.trainingCost
    preds = model.transform(sdf_scaled)
    sil = evaluator.evaluate(preds)
    elbow_rows.append({"k": k, "Inertia": cost, "Silhouette": sil})

elbow_df = pd.DataFrame(elbow_rows)
print(elbow_df)

4 Classification Models

Two supervised models are trained to predict whether a job posting is AI-related, using experience, education, and occupational classification as features. Since AI-related jobs make up only ~28% of postings, class weights are computed and applied (equivalent to scikit-learn’s class_weight="balanced") to prevent the models from defaulting to the majority class.

features = ["MIN_YEARS_EXPERIENCE", "MIN_EDULEVELS_CLEAN", "SOC_ENC", "ONET_ENC"]
assembler2 = VectorAssembler(inputCols=features, outputCol="features_raw2")
sdf_feat = assembler2.transform(sdf_clustered)

scaler2 = StandardScaler(inputCol="features_raw2", outputCol="features_scaled2", withMean=True, withStd=True)
scaler2_model = scaler2.fit(sdf_feat)
sdf_feat_scaled = scaler2_model.transform(sdf_feat)

train_df, test_df = sdf_feat_scaled.randomSplit([0.8, 0.2], seed=42)

counts = {row["AI_JOB"]: row["count"] for row in train_df.groupBy("AI_JOB").count().collect()}
total = sum(counts.values())
w0 = total / (2 * counts[0])
w1 = total / (2 * counts[1])
train_df = train_df.withColumn("weight", when(col("AI_JOB") == 1, w1).otherwise(w0))
print(f"Class weights -> Non-AI: {w0:.3f}, AI-Related: {w1:.3f}")

lr = LogisticRegression(featuresCol="features_scaled2", labelCol="AI_JOB", weightCol="weight", maxIter=1000)
lr_model = lr.fit(train_df)
lr_pred = lr_model.transform(test_df).select("AI_JOB", "prediction").toPandas()

rf = RandomForestClassifier(featuresCol="features_raw2", labelCol="AI_JOB", weightCol="weight", numTrees=100, seed=42)
rf_model = rf.fit(train_df)
rf_pred = rf_model.transform(test_df).select("AI_JOB", "prediction").toPandas()

5 Summary

This ML analysis extends the EDA by applying PySpark MLlib clustering and classification models to the AI vs. Non-AI career question.

Key findings:

  • AI-related jobs represent approximately 28% of postings after filtering invalid placeholder records, confirming that AI has broadly permeated the labor market beyond a narrow technical niche
  • A data quality issue was identified and corrected: the education field used code 99 as a “missing data” flag, which was distorting both clustering and classification results
  • The elbow method and silhouette score jointly support k=3 as the optimal number of clusters, yielding interpretable groups differentiated primarily by years of experience
  • AI job density is highest among lower-experience clusters (~30%) and lowest among senior/high-experience roles (10.9%), suggesting AI roles concentrate earlier in career trajectories
  • Logistic Regression and Random Forest achieve ~67% accuracy and F1 scores of ~0.43 after correcting the education feature and applying balanced class weights
  • Years of experience is by far the dominant predictor of AI job classification (88.5% importance), far outweighing education (11.5%) and occupational codes (~0%)

Recommendations for job seekers:

  • Early-to-mid career professionals are well-positioned to enter AI-adjacent roles, since AI job density is highest in lower-experience clusters
  • Formal education level matters less than expected — occupational and skills alignment appear more important than degree level alone
  • Build demonstrable experience with data science, analytics, or ML tools early in one’s career, since experience — not credentials — is the strongest signal in this analysis
  • Target industries like Professional Services, Finance, and Information Technology where AI hiring is most concentrated
